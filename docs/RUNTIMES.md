# Variantes de runtime

O launcher oferece três referências independentes: **Cmod**, **Ludashi** e **Vanilla**. A seleção é salva localmente em `runtimeVariant`; o launcher não baixa, instala ou mistura APKs automaticamente.

| Variante | Repositório |
|---|---|
| Cmod/Bionic | https://github.com/coffincolors/winlator |
| Ludashi | https://github.com/StevenMXZ/Winlator-Ludashi |
| Vanilla/Bruno Dev | https://github.com/brunodev85/winlator |

Compatibilidade e desempenho dependem da GPU, driver Vulkan, versão do Android, arquitetura e aparelho. Use somente builds e arquivos que você tenha autorização para utilizar.
